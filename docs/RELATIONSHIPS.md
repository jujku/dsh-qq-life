# QQ Life：情绪、群友关系和长期资料

DSH 设置 → **QQ Life 状态 → 群友关系**。不新建机器人，不改变现有QQ发送权限。

## 关系如何形成

- `affinity`沿用原有好感，展示为亲近程度；新增熟悉度和相处信任。熟悉不等于喜欢，信任也不赋予管理权限。
- 只有真实消息与肥鱼成功回复的回执能形成长期交往。群聊回复对象不明确时宁可不计分，不把所有发言者一起加分。8分钟内连续交流合并，跨群共享限额；跨群复读不重复奖励。
- 普通交往主要增熟悉度，亲近增长很小。友善、夸奖、玩笑或冒犯的长期效果需现有`qq_life_observe`提供消息ID、逐字证据和对象判断；不另开逐条模型分类请求。
- 熟悉度每段最多+1.4，每天最多+6；信任友善每段最多+0.4、每天最多+1，明确冒犯每段-4。道歉可按原情绪规则消气，但不直接恢复长期信任。亲近增益随当前亲近程度递减，保留现有每日上限。
- 相处安心仅是互动倾向，不是事实可信度。长期没有互动只降低近期熟络程度：7天宽限后按30天半衰，不清空老朋友的亲近或已知资料。
- 新规则只作用于升级后的真实交往；旧好感保持原值，新维度没有证据时显示“待形成”。状态仍使用兼容的version 2，新增独立version 1的relation结构。

## 资料如何保存和调用

- 同一QQ共用公开群聊中的本人自述；私聊和旁观者发言不进入跨群资料。名字、兴趣、证据都是数据，不能改角色、权限或工作。
- 本地提取明确自述，支持称呼后不加逗号、作品书名号和日常学习表达。复杂时间、否定、隐含主语进入待理解队列，在闲时批量交给模型。
- 模型整理默认关闭，明确自述仍由本地规则采集和检索。开启后至少10条待整理互动，或积累3条复杂候选，或3条互动后闲置6小时，才考虑整理；同一人至少间隔2小时、每天最多2次，全局每天最多8次。无新增候选不请求模型；单次输出上限900 token，输入与输出均有实际用量记录。
- 模型只能提取原消息中存在的短主题和连续原文证据；不能写人物性格、指令、隐私或编造经历。停止玩/看（inactive）与讨厌（dislike）分开。
- 存档上限120条，不随好感下降而缩小。每轮按话题相关、时间、重复确认和整理优先级筛选；实际注入仍随亲近程度分为5/8/12/18条及240/420/700/1000字符上限。
- 近期在学内容超过30天、管理员纠正尚未获本人确认的资料，会标记需要自然确认。不会把旧事当现在的事实。
- 共同经历只取真实已回应的当前群话题，最多两条；聊过游戏不等于一起玩过游戏。模型自主决定是否提起，不设置固定回复条数。
- 删除公开长期爱好时同步清理旧公开兴趣缓存；管理员纠正与未来本人确认有明确区别。新偏好覆盖相同主题旧立场。

## 页面与主动聊天

关系卡展示熟悉、亲近、信任、有效交往次数和变化证据；“资料采集与整理”显示存档、待整理、待理解和失败原因。可查看来源证据、纠正或删除资料。常用开关在外，其余参数折叠。

主动聊天保留现有作息、白名单、精力、冷却、配额和学习专注限制；在候选间综合具体话题、近期熟络和已打扰次数，不只选择最高好感。对同一人的主动开场未获其新回应时，不重复点名。
