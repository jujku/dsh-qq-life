# 数据、模型请求与边界

本插件不含遥测或公开上传接口。运行时读取管理员设置的本地 qq-bridge 数据。主动聊天通过本机桥接唤醒现有会话，不直接登录 QQ。

| 文件                         | 内容                                               |
| ---------------------------- | -------------------------------------------------- |
| connection.json              | 本机桥接目录，不含 API Key                         |
| config.json                  | 参数、角色称呼、主动聊天群号、模型 ID              |
| state.json / state.json.prev | 情绪、群友 QQ 号、昵称、关系与交往证据             |
| person-memory.json           | 群友公开自述、来源证据、待整理原文、摘要任务及用量 |

管理页可以纠正、删除群友资料和调整分数。删除是当前存档层面的管理操作；state.json.prev 或管理员自己备份中的旧数据不自动清除，永久清理时一并处理自己的备份。

公开长期资料跨群按同一 QQ 号使用，仅对本人召回，不把私聊搬到公开资料。群内兴趣仍有群范围；共同话题来自真实对话，不声称一起玩过或看过。关系值不是权限或事实可信度。

普通回复会把选中的关系和资料提示交给原会话模型。开启 semanticMemoryEnabled 后，资料整理还会通过 DSH 将公开原文候选交给所选模型。限频不等于零花费或硬 token 总预算。API Key 由 DSH 管理，不写进本插件存档。

字段中的指令不能改变人设或授权；姓名、兴趣和证据作为数据注入。插件管理接口禁止 agent token 和跨来源修改请求，要求回环 Host，同源 POST 和 JSON 请求；外层登录由 DSH 提供。不要绕过外层登录单独公开这些路由。
